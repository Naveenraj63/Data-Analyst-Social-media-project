Social Media Campaign Performence Tracker:
Project Overview:

This Power BI project visualizes student attendance data in an interactive and insightful way. It helps track the total number of students, their attendance status, team distribution, and performance averages using dynamic visuals and filters.

Files Included:

Power Bi.pbix – Power BI dashboard file
Student Personal Details.xlsx – Dataset used for the dashboard
Screenshot.png – Preview of the dashboard

Dashboard Highlights:

Total Enrolled: 23 students
Present: 20 students
Absent: 3 students
Average Attendance: 86.96%

Visual Insights:

Team Wise Report – Displays attendance by team.
Manager Wise Report – Shows attendance managed under each supervisor.
Gender Wise Report – Compares male and female student distribution.
Level Wise Report – Shows the job level or position-based attendance data.
Filters
Training Model
Senior Manager
Team
Job Level

Tools & Technologies:

Microsoft Power BI
Excel (for data source and preprocessing)

Key Learnings:

Data cleaning and transformation using Power Query.
Designing professional dashboards with KPIs and visuals.
Applying slicers and filters for better interactivity.
Improving data-driven decision-making through visualization.

How to Use:

Download both .pbix and .xlsx files.
Open the .pbix file in Power BI Desktop.
Connect the Excel file as the data source (if prompted).
Refresh the dashboard to view all visuals.
